# 🧩 Tile Match 3

**Match 3 of a kind. Trigger combos. Beat all 30 levels.**

A polished mobile-first match-3 puzzle (Bejeweled / Candy-Crush style). Swap adjacent tiles to line up 3 or more, set off cascading combos, and create explosive special tiles to clear each level's objective before you run out of moves.

## ▶️ Play

**[xniperbuilds.github.io/tile-match-3](https://xniperbuilds.github.io/tile-match-3/)**

## 🎮 How to play

- Tap two neighbouring tiles (or swipe) to **swap** them.
- Line up **3+** of one color to clear them.
- Match **4** = striped (clears a row/col), **5** = color bomb, **L/T** = bomb (3×3)!
- Chains **cascade** for big combo points.
- Hit the level objective before your moves run out.

## ✨ Features

- 8×8 board, 6 colors, 4 special tile types + combos
- Cascading chain reactions with escalating combo scoring
- 30 levels (score + color-clear objectives) then endless
- 1/2/3 star ratings per level — replay to perfect them
- Auto-shuffle when no moves remain
- 8 achievements, stats, 5 tiers (Beginner → Legend)
- Real-time global **leaderboard** (Today / This Week / All Time)
- Shareable score card; works offline after first load

## 🛠️ Tech

Single self-contained `index.html` — vanilla JS, CSS animations, Web Audio API, and a realtime backend for the leaderboard. No build step, no install.
